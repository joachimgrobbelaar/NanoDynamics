⚛️ Astrodynamics & Perturbation Equations

Every trajectory step integrates the sum of gravitational, atmospheric, radiative, and electrodynamic accelerations in the Earth-Centered Inertial (ECI) frame:

$$\mathbf{a}_{\text{total}} = \mathbf{a}_{\text{central}} + \mathbf{a}_{J_2} + \mathbf{a}_{J_3} + \mathbf{a}_{J_4} + \mathbf{a}_{J_{2,2}} + \mathbf{a}_{\text{drag}} + \mathbf{a}_{\text{SRP}} + \mathbf{a}_{\text{moon}} + \mathbf{a}_{\text{sun}} + \mathbf{a}_{\text{tide}} + \mathbf{a}_{\text{mag}}$$

1. Earth Higher-Order Geopotential Harmonics

$J_2$ Oblateness (Equatorial Bulge):

$$\mathbf{a}_{J_2} = -\frac{3}{2}\frac{J_2 \mu R_E^2}{r^5} \left[ x\left(1 - \frac{5z^2}{r^2}\right)\hat{\mathbf{i}} + y\left(1 - \frac{5z^2}{r^2}\right)\hat{\mathbf{j}} + z\left(3 - \frac{5z^2}{r^2}\right)\hat{\mathbf{k}} \right]$$

$J_3$ Pear-Shaped Asymmetry ($J_3 = -2.532 \times 10^{-6}$):

$$\mathbf{a}_{J_3} = -\frac{5}{2}\frac{J_3 \mu R_E^3}{r^7} \left[ x z \left(3 - \frac{7z^2}{r^2}\right)\hat{\mathbf{i}} + y z \left(3 - \frac{7z^2}{r^2}\right)\hat{\mathbf{j}} + \left(6z^2 - \frac{7z^4}{r^2} - \frac{3}{5}r^2\right)\hat{\mathbf{k}} \right]$$

$J_{2,2}$ Longitudinal Ellipticity ($C_{2,2}=1.57 \times 10^{-6}, S_{2,2}=-9.04 \times 10^{-7}$): Drives longitudinal GEO drift toward stable potential wells at $75.1^\circ\text{E}$ and $105.3^\circ\text{W}$.

2. Attitude-Dependent Aerodynamic Drag

Satellite pitch ($\alpha$), yaw ($\beta$), and roll ($\gamma$) dynamic cross-sectional area scaling:

$$A_{\text{eff}}(\alpha, \beta) = A_{\text{ram}} |\cos\alpha \cos\beta| + 2.5 A_{\text{side}} |\sin\alpha| + 2.0 A_{\text{top}} |\sin\beta|$$ $$\mathbf{a}_{\text{drag}} = -\frac{1}{2} \rho(h) C_D \frac{A_{\text{eff}}}{m} \|\mathbf{v}_{\text{rel}}\| \mathbf{v}_{\text{rel}}$$

3. Solar Radiation Pressure (SRP) Ray-Tracing Shadow

Ray-sphere cylindrical occultation factor $\nu \in [0, 1]$ (Umbra $\nu=0$, Penumbra $0 < \nu < 1$, Direct Sun $\nu=1$):

$$\mathbf{a}_{\text{SRP}} = -P_{\text{sun}} \left(\frac{1\text{ AU}}{d_{\text{sun}}}\right)^2 \left(\frac{C_R A_{\text{eff}}}{m}\right) \nu \hat{\mathbf{u}}_{\text{sun}}$$

4. Geomagnetic Dipole & Lorentz Perturbation

$$\mathbf{B}(\mathbf{r}) = \frac{B_0 R_E^3}{r^3} \left[ 3(\hat{\mathbf{m}} \cdot \hat{\mathbf{r}})\hat{\mathbf{r}} - \hat{\mathbf{m}} \right], \quad \mathbf{a}_{\text{mag}} = \frac{q}{m} (\mathbf{v} \times \mathbf{B})$$

🧠 Symplectic Physics-Informed Neural Network (PINN)

Standard deep neural networks incur secular orbital energy drift over multi-orbit horizons. NanoDynamics enforces a canonical Hamiltonian phase space structure:

$$\mathcal{H}(\mathbf{q}, \mathbf{p}) = \frac{1}{2}\mathbf{p}^T \mathbf{M}^{-1} \mathbf{p} + V(\mathbf{q}), \quad \frac{d\mathbf{q}}{dt} = \frac{\partial \mathcal{H}}{\partial \mathbf{p}}, \quad \frac{d\mathbf{p}}{dt} = -\frac{\partial \mathcal{H}}{\partial \mathbf{q}}$$ 
# PyTorch Symplectic Hamiltonian Loss Function
import torch
import torch.nn as nn

class SymplecticLoss(nn.Module):
    def __init__(self, lambda_pde=1.0, lambda_ham=0.1):
        super().__init__()
        self.lambda_pde = lambda_pde
        self.lambda_ham = lambda_ham
        self.mse = nn.MSELoss()

    def forward(self, q_pred, p_pred, q_true, p_true, mu=3.986e14):
        loss_data = self.mse(q_pred, q_true) + self.mse(p_pred, p_true)
        # Hamiltonian H = 0.5 * |p|^2 - mu / |q|
        h_pred = 0.5 * torch.sum(p_pred**2, dim=-1) - mu / torch.norm(q_pred, dim=-1)
        h_true = 0.5 * torch.sum(p_true**2, dim=-1) - mu / torch.norm(q_true, dim=-1)
        loss_hamiltonian = self.mse(h_pred, h_true)
        return loss_data + self.lambda_ham * loss_hamiltonian

⚡ Google Cloud Compute Engine (A100) & Dual-ESP32 HIL

Training and quantization were executed on Google Cloud Compute Engine infrastructure:

  • Instance Tier: a2-highgpu-1g (Google Cloud us-central1)
  • Accelerator: 1x NVIDIA A100 Tensor Core GPU (40 GB SXM4, 312 TFLOPS TF32)
  • Compute Environment: Ubuntu 22.04 LTS, CUDA 12.2, PyTorch 2.3.0+cu121, TensorRT 8.6
  • Quantization Pipeline: PyTorch FP32 → ONNX → TensorFlow Graph → TFLite Post-Training Quantization (PTQ INT8)

Dual-ESP32 Edge Deployment:

  • Node 1 (Gateway): ESP32-WROOM-32 running ESP-NOW to UART bridge and WebSocket proxy.
  • Node 2 (Inference Core): ESP32-S3 (Xtensa Dual-Core 240 MHz, 512 KB SRAM) hosting TensorFlow Lite for Microcontrollers within a 40 KB Tensor Arena.
  • Measured Benchmark: 1.85 ms inference latency, 0.584 mJ step energy consumption, zero secular energy drift over 24-hour simulation cycles.
